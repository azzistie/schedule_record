# 时间账本 · iOS

原生 SwiftUI 应用，支持 iOS 17 及以上。时间记录保存在设备本地，日历通过 EventKit 接入。

## 功能

- **消息记录**：输入“阅读”等事项，点击发送，记录从上一条记录的结束时间到点击发送的时间。当天表格立即更新，空白时段显示“未记录”。输入内容作为事项名称保存，不依赖云端 AI。
- **手动补记 / 修正**：指定开始、结束和事项；覆盖已有区间前确认，保留原记录不重叠的部分。支持跨午夜和跨多条记录。补记较早的时段不会让下一次消息的起点倒退。
- **汇总表格**：所有日期的记录、按日期筛选、关键词搜索、删除确认，以及全部记录 CSV 导出。
- **关键词统计**：自定义过去 1–3650 天，包含今天；柱状图、折线图、总时长、日均、最大单日时长、有记录天数和每日明细。关键词按包含关系匹配，不区分大小写。无记录日期计为零。
- **未来待办**：选择系统日历、起止时间、备注和提前提醒。保存为日历事件；显示未来 30 天的系统日历安排。可在系统日历中修改或删除。

## 时间规则

1. 第一条记录默认从当天 00:00 开始，用户可以修改“本次开始”。之后使用所有记录中最晚的结束时间，包括前一天的记录。
2. 忘记记录时，先补记准确时间段，或发送后通过补记修正。应用不会猜测未记录期间的活动。
3. 区间采用 `[开始, 结束)`，相邻记录不会冲突；补记重叠时拆分原区间，防止双重计时。
4. 每日展示和统计按照设备当前时区划分自然日，跨天记录分摊到各天。更换设备时区后，每日归属随之变化。以秒保存时长，界面分钟向下取整。
5. 删除跨天记录会删除整条原始记录，界面会先确认。调整其中一部分请使用补记。
6. 日均 = 匹配总时长 / 选择的天数，包括无记录日及尚未结束的今天。

## 在 Mac 上运行

此源码在 Windows 环境创建，尚未用 Xcode 编译或进行模拟器 / 真机测试。

需要 Mac、支持 iOS 17 的 Xcode 和 XcodeGen。在项目目录执行：

```sh
brew install xcodegen
xcodegen generate
open TimeLedger.xcodeproj
```

在 Xcode 中选择 `TimeLedger` target，在 Signing & Capabilities 中选择自己的 Team，并把 `com.example.TimeLedger` 改为唯一的 Bundle Identifier。选择 iPhone 模拟器后运行；安装到自己的 iPhone 需要配置签名。

使用 Product → Test 执行 `TimeLedgerTests`。测试覆盖重叠拆分、多记录覆盖、相邻区间、补记起点、跨午夜、夏令时、空白日期、非法输入及 CSV 转义。

命令行测试（设备名称以本机已安装模拟器为准）：

```sh
xcodebuild -project TimeLedger.xcodeproj -scheme TimeLedger -destination 'platform=iOS Simulator,name=iPhone 16' test
```

## 验收操作

1. 调整第一次开始时间，输入“阅读”发送，确认表格起止时间和时长。
2. 再发送“工作”，确认从上一条结束开始，且没有重叠。
3. 在上一条内部补记“午饭”，确认提示覆盖，并拆分为前、中、后三段。
4. 补记跨午夜的活动，在总表和统计中验证每天分摊及总时长。
5. 搜索关键词，比较图表、每日明细和 CSV。选择无记录关键词，确认显示为零。
6. 重启应用确认记录仍在。导出 CSV 并用 Numbers / Excel 打开。
7. 拒绝日历权限后确认记录功能仍可用；在设置恢复权限后返回应用。
8. 连接日历，新建未来事件并检查系统日历、提醒、刷新与跨设备账户同步。

## 数据与边界

时间数据原子写入 Documents/time-ledger.json。读取失败时停止写入，避免覆盖原文件。已启用文件共享，可通过 Finder 的设备文件共享备份原始 JSON；CSV 是导出格式，目前不支持导入。

当前版本的消息输入位于应用内，不接收微信、短信或 Siri 消息。时间记录尚无应用内云同步。待办使用系统日历事件，尚无完成勾选、重复任务或独立任务列表。日历提醒由系统和用户设置控制。应用尚未签名、打包 IPA 或上架 App Store。
